# Software Design Coordination with TENT

**Author: Trevor Hardy**

**Last Updated: 7 Oct 2026**

[TENT is the Transactive Energy Network Template](https://www.pnnl.gov/main/publications/external/technical_reports/PNNL-28420Ver4.pdf), an effort in the Transactive Systems Program that originated in the Transactive Campus work as a part of the same program. Though originally tightly integrated with VOLTTRON and thus designed around implementing ideas to directly control devices, it has matured and grown from that start and is now distinct.

Given that both TENT and TESP have transactive system modeling and simulation capabilities and reside in the same program, there is good reason to believe that much of their code could be common. Discussions in the last quarter of FY26 around future work integrating the two were had and some of that is represented in the files in this folder; this is far from a comprehensive record.
