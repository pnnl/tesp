# Execution 

**Author: Trevor Hardy**

**Last Updated: 4 Nov. 2026**

In FY27 the TESP team is attempting to standardize the way in which TESP based analysis are instantiated and executed. Doing so is expected to better support both humans and LLMs that are attempting to build a TESP-based simulation by more explicitly  showing the steps and necessary processes of each step. In the past this process was developed _ad-hoc_ and was not well-designed or supported.
